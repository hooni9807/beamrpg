# 임희범 키우기 · BeamRPG

마을을 이동해 탁구 고수에게 도전하고, 승리로 경험치와 스탯 포인트를 얻는 브라우저 RPG입니다.

- 방향키 또는 WASD로 마을 이동
- NPC와 11점 탁구 대결
- 승리 시 경험치 +120, 레벨업 시 스탯 포인트 +3
- 레벨 10에서 필살기 해금
- 진행 상태는 브라우저에 저장

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages로 자동 배포합니다. 저장소 Settings → Pages에서 Source를 **GitHub Actions**로 한 번만 선택하면 됩니다.

로컬에서는 `index.html`을 브라우저에서 열면 실행됩니다.
