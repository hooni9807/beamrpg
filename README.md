# BeamRPG · 대환장 파티

> 희범의 집부터 챔피언의 경기장까지. 7부부터 1부까지 마을을 여행하고, 선수촌의 탁구 마왕에게 도전하는 브라우저 성장 RPG.

**[게임 바로 하기](https://hooni9807.github.io/beamrpg/)**

## 짧은 프롤로그

첫 접속에는 **초대장 도착 → 아재범의 도전 → 탁구 마왕 → 희범의 출발**로 이어지는 네 장면이 나옵니다. 실제 게임 지도 위에 카메라 연출과 짧은 대사를 더했습니다. 다음 버튼으로 읽는 속도에 맞춰 넘기거나 언제든 건너뛸 수 있습니다.

완료하거나 건너뛰면 같은 브라우저에서 자동으로 반복되지 않습니다. 기존 이용자도 업데이트 후 한 번 볼 수 있으며, 레벨·라켓·위치·보스 기록은 바뀌지 않습니다. **안내 → 스토리 다시 보기**에서 다시 볼 수 있습니다.

## 게임 흐름

1. 시작 캐릭터는 **희범**입니다. 바깥 **리그 로드**에서 열린 마을 입구까지 걸어 들어갑니다.
2. 집에서 쉬고, 라켓을 준비하고, 공원과 마을 시설을 둘러보세요. 카메라가 희범을 따라 넓은 지도를 비춥니다.
3. 마을 외곽을 걷다 확률적으로 몬스터를 만나 **기술을 선택하는 턴제 전투**를 펼칩니다. **체육관 보스**는 기존 탁구 스윙 경기로 대결하며, 이기면 다음 마을이 열립니다.
4. 레벨업 때 무작위로 나온 3개 강화 중 하나를 선택합니다.
5. 레벨 2 / 4 / 7 / 10 / 13에 일반 몬스터 전투에서 직접 고르는 새 기술을 배웁니다.

## 일반 몬스터 전투와 HP

포켓몬 본편의 기술 선택·PP·선공·상성 구조를 참고한 희범 1인 턴제 전투입니다. **상대 HP를 먼저 0으로 만들면 승리**합니다. 마을마다 통통볼·스핀젤리·커트고슴이 지역에 맞는 이름과 레벨로 등장합니다.

- **기술:** 네 기술 중 하나를 고르면 상대도 기술을 골라 행동합니다. 우선도가 높은 기술이 먼저, 우선도가 같으면 스피드가 높은 쪽이 먼저 행동하며 동률은 무작위입니다. 먼저 쓰러진 쪽은 반격하지 않습니다.
- **데미지:** 레벨·위력·공격/방어 또는 특수공격/특수방어에 명중률·급소·데미지 변동을 적용합니다. 회전 커트는 상대 스피드를 낮출 수 있고, 철벽 준비는 방어·특수방어를 올립니다. 능력 변화는 해당 전투에만 적용합니다.
- **DP 타입 상성:** 포켓몬스터 DP의 노말·불꽃·물·전기·풀·얼음·격투·독·땅·비행·에스퍼·벌레·바위·고스트·드래곤·악·강철 17타입의 단일 타입 상성을 사용합니다. 희범은 새 여정 시작 시 무작위 타입을 받고 저장되며, 일반 몬스터와 보스·코치도 만날 때 무작위 타입을 받습니다. 기술마다 타입이 있어 상대에게 2배, ½배, 무효 또는 일반 피해가 적용되고, 희범 자신의 타입과 같은 기술은 1.5배 피해를 줍니다. 전투 화면의 기술 버튼에서 현재 상대에게 적용될 결과를 바로 확인할 수 있습니다.
- **PP:** 기술마다 사용 횟수가 있습니다. 모두 소진하면 반동 피해를 받는 최후의 발악을 사용합니다. 라켓을 바꾸어도 이미 사용한 필살기 PP는 회복되지 않습니다.
- **가방:** 시작 회복약 3개. 회복약은 HP 40을 회복하고 한 턴을 사용합니다. 치유 센터에서 25 G에 추가 구입할 수 있습니다.
- **도망:** 성공하면 보상 없이 마을로 돌아갑니다. 실패하면 상대가 공격합니다. 스피드와 시도 횟수에 따라 성공률이 높아집니다.

희범은 **HP 64**로 시작하고 레벨마다 최대 HP가 8씩 증가합니다. 남은 HP와 PP는 전투가 끝나도 유지됩니다. **희범의 집·각 지역 숙소·치유 센터에서 무료로 완전히 회복**할 수 있습니다. 패배하면 현재 마을 치유 센터로 돌아와 치료받으며 경험치와 골드는 잃지 않습니다. 보스와 코치의 탁구 경기는 HP·PP를 소모하지 않습니다.

일반 전투는 기술 선택 한 턴이 끝날 때마다 자동 저장됩니다. 새로고침하거나 브라우저를 다시 열면 상대 HP·희범 HP·PP·턴을 이어받습니다. 승리 보상은 결과 화면에서 마을로 돌아갈 때 한 번만 지급됩니다.

## 마을과 생활 시설

건물은 입구에 닿으면 내부 지도로 이어집니다. 출구에 닿으면 마을로 돌아오고, 마을 귀환 지점에서는 바깥 리그 로드로 나갑니다. 지도나 목적지 목록을 선택하면 건물과 물을 피해 걸어갑니다.

| 시설 | 이용 내용 |
| --- | --- |
| 희범의 집 / 지역별 숙소 | 무료 HP·PP 완전 회복 + 공격형 휴식 버프 |
| 지역별 공원 | 별도 공원 지도를 산책 + 민첩형 휴식 버프 |
| 라켓 공방 | 라켓 구입·장착, 라켓별 특성과 필살기 확인 |
| 랠리 카페 | 샌드위치 40 G: 다음 3번 승리 경험치 +20% |
| 트레이닝 센터 | 코치와 연습 경기, 마을별 첫 훈련 승리에 해당 마을의 일반 승리 XP 지급 |
| 치유 센터 | 무료 HP·PP 완전 회복 + 방어형 휴식 버프, 회복약 25 G 구입 |
| 리그 기념관 | 8개 지역의 보스 격파와 트로피 기록 확인 |
| 체육관 / 경기장 | 해당 마을 보스에게 도전 |

휴식하면 다음 **3번 전투**에 적용되는 버프를 얻습니다. 버프는 중첩되지 않으며, 다른 휴식 장소를 이용하면 새 버프로 교체됩니다. 일반 턴제 전투와 보스·훈련 탁구 경기 모두에 반영됩니다.

| 장소 | 버프 | 일반 턴제 전투 | 보스·훈련 탁구 경기 |
| --- | --- | --- | --- |
| 희범의 집 / 숙소 | 정비된 루틴 · 공격형 | 공격·특수공격 +15% | 타구 속도·회전 +15% |
| 공원 | 산책의 리듬 · 민첩형 | 스피드 +25%, 급소 +10%p | PERFECT 판정 폭 +20%, 게이지 획득 +20% |
| 치유 센터 | 회복 보호막 · 방어형 | 방어·특수방어 +25% | 회전 실수 확률 −20%, PERFECT 판정 폭 +10% |

집과 치유 센터는 HP·PP도 완전히 회복하며, 공원은 HP·PP 회복 없이 버프만 제공합니다. 카페 식사는 효과가 남아 있는 동안 다시 구매할 수 없습니다. 훈련 재경기는 연습용이며 추가 경험치·골드를 지급하지 않습니다.

새로 시작하면 **120 G**를 받습니다. 일반 승리 보상은 7부의 45 G부터 지역마다 10 G씩, 보스 승리는 120 G부터 지역마다 20 G씩 증가합니다.

| 라켓 | 가격 |
| --- | ---: |
| 일반 라켓 (특수 효과 없음) | 기본 지급 |
| 쉐이크핸드 | 120 G |
| 중국식 펜홀더 | 150 G |
| 일본식 펜홀더 | 200 G |
| 수비수 라켓 | 180 G |

구입한 라켓은 공방에서 자유롭게 바꿀 수 있습니다. 라켓마다 타구 특성과 레벨 2 필살기가 다릅니다.

## 성장

레벨업 때 아래 능력치 가운데 3개가 무작위로 제시됩니다. 하나를 고르면 해당 능력치가 성장합니다.

| 능력치 | 일반 턴제 전투 (1포인트당) | 보스·훈련 탁구 경기 |
| --- | --- | --- |
| 파워 | 공격 +5% | 타구 속도 +5% |
| 회전 | 특수공격 +5% | 타구 회전 +5% |
| 컨트롤 | 방어 +5% | PERFECT 타이밍 폭 +3% |
| 풋워크 | 스피드 +5% | 회전 공 실수 확률 −10% |
| 치명타 | 급소 확률 +5%p, 최대 50% | 치명타 확률 +5% (타구 속도 2배) |
| 집중력 | 특수방어 +5% | 필살기 게이지 획득 +10% |

지역 보스는 그 마을보다 한 부수 위 실력으로 나오고, 선수촌의 탁구 마왕은 보스전 난이도입니다. 탁구 경기의 필살기 게이지는 레벨 2부터 찹니다. 게이지가 찬 보스·훈련 경기에서는 현재까지 배운 기술 중 하나가 무작위로 발동합니다. 탁구 경기 중 **마을로 도망**을 누르면 보상이나 경험치 손실 없이 돌아옵니다.

레벨, 스탯, 보스 격파, 위치, 미선택 강화, 골드, 보유 라켓, 시설 효과, HP·PP·회복약·진행 중인 일반 전투는 같은 브라우저의 `localStorage`에 자동 저장됩니다. 기존 `beamrpg.v3` 또는 이전 `beamrpg.v2`의 성장·보스 기록을 이어받으며, HP가 없던 이전 저장에는 현재 레벨의 최대 HP와 회복약 3개를 지급합니다. 새 게임은 희범의 집에서, 이어하기는 마지막으로 저장된 위치에서 시작합니다. 이전 버전에서 이미 열린 선수촌도 계속 방문할 수 있습니다. 로그인 없이 플레이할 수 있습니다.

Lv.1 기술은 포핸드 드라이브·쾌속 쇼트·회전 커트·철벽 준비입니다. 레벨업 기술은 기존 기술을 교체하지 않고 계속 추가되어, 일반 몬스터 전투 화면에서 모두 선택할 수 있습니다. 보스·훈련 경기에서는 게이지가 찰 때 이 레벨업 기술들 가운데 하나가 무작위로 발동합니다.

## 조작

- 지도: 클릭/터치, 목적지 목록, 방향키 또는 `WASD`, 화면 방향 버튼으로 이동합니다. 희범의 팔·다리가 움직이고 카메라와 미니맵이 현재 위치를 보여 줍니다.
- 입구·출구: 걸어서 닿으면 다음 지도로 이동합니다. 목적지 목록도 즉시 이동이 아닌 걷기 안내입니다.
- 시설: 내부 이용 지점에 닿거나 가까이에서 `E`를 누릅니다. 체육관에서는 보스 도전 버튼으로 대결을 시작합니다.
- 일반 상대: 마을 외곽을 걷는 동안만 확률적으로 조우합니다. 원형 표식으로 돌아다니는 상대는 없으며, 가만히 서 있거나 광장·시설 주변·건물 내부·공원에 있으면 조우하지 않습니다. 입장·대결 종료 직후에도 잠시 안전하게 이동할 수 있습니다.
- 일반 전투: 기술·가방·상태·도망 메뉴를 클릭/터치하거나 `Tab`·`Enter`로 선택합니다. `Esc`는 기술 메뉴로 돌아가며 전투를 종료하지 않습니다.
- 보스·훈련 경기: 공의 타이밍 링이 맞는 순간 드래그해 스윙합니다. 탭/클릭은 쇼트 또는 블록, `Space`는 일시정지입니다.

## 저장과 Firebase

BeamRPG는 SPIN LAB과 **완전히 별개의 프로그램**입니다. 탁구 엔진 코드는 SPIN LAB에서 가져왔지만, 저장소·Firebase·온라인 방은 공유하지 않습니다.

- 기본은 기기 저장입니다. RPG 진행 `beamrpg.v3`, 경기 설정·기록 `beamrpg.game.*` (SPIN LAB의 `spinlab.*`와 섞이지 않음)
- **클라우드 저장(선택)**: 지도 화면의 **☁ Google 로그인**을 누르면 RPG 진행(레벨·경험치·스탯·위치·HP·코인·라켓 등)을 BeamRPG 전용 Firebase에 저장해, 다른 기기에서 같은 계정으로 로그인하면 이어서 할 수 있습니다.
  - 저장은 바뀐 뒤 8초 안에, 그리고 화면을 벗어날 때 올라갑니다. 로그인하면 계정에 저장된 더 최신 진행을 불러옵니다.
  - 진행이 있는 기기에서 처음 로그인했는데 계정에도 진행이 있으면 어느 쪽을 쓸지 묻습니다.
  - 로그인한 적 없는 기기는 Firebase를 아예 불러오지 않습니다.
- 탁구 엔진에 남아 있는 예전 SPIN LAB 온라인 기능(랭킹·PvP·설정 동기화)은 꺼져 있습니다(`index.html`의 `FIREBASE_CONFIG=null`).
- 온라인 방 ID 접두어: `beamrpg-` (SPIN LAB 방과 매칭되지 않음)

### BeamRPG 전용 Firebase 프로젝트

| 항목 | 값 |
| --- | --- |
| 프로젝트 | `beamrpg` (ID `beamrpg-e22ac`), 웹 앱 `beamrpg-web` · 애널리틱스·Gemini 끔 |
| 인증 | Google 로그인 · 승인된 도메인 `hooni9807.github.io`, `localhost` |
| Firestore | 서울(`asia-northeast3`) · 문서 `saves/{uid}` = `{data, rev, level, at}` |
| 보안 규칙 | [`firestore.rules`](firestore.rules) · 본인 `saves/{uid}`만 읽기·쓰기, 그 외 전부 차단 |
| 코드 | [`cloud.js`](cloud.js) (설정값 포함) |

규칙을 바꾸면 Firebase 콘솔 → Firestore → 규칙에 `firestore.rules` 내용을 붙여 넣고 게시합니다. 네이버 로그인을 쓰려면 BeamRPG용 네이버 앱과 [`naver-worker.js`](naver-worker.js) 워커를 따로 만들어야 합니다.

## 로컬 실행

별도 설치가 필요 없습니다. `index.html`을 브라우저에서 열면 됩니다.

## 배포

`main`에 푸시하면 [GitHub Actions](.github/workflows/deploy-pages.yml)가 GitHub Pages로 자동 배포합니다. 저장소에서 처음 한 번만 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정하면 됩니다.

## 기술

- 빌드 도구 없이 실행하는 HTML/CSS/JavaScript 게임
- `towns.js`: 마을 이동, 경로 탐색, 시설, 성장과 저장
- `towns-renderer.js`: Canvas 지도와 희범의 걷기 모션
- `towns.css`: 지도 HUD, 목적지 목록, 모바일 레이아웃
- `story.js` / `story.css`: 첫 실행 프롤로그와 다시 보기
- `combat.js`: 일반 전투 계산, 기술·몬스터, HP·PP와 전투 저장 검증
- `combat-ui.js` / `combat.css`: 턴제 전투 화면과 원작 캐릭터 애니메이션
- 기존 Canvas 탁구 대결 엔진 연동
- GitHub Pages + GitHub Actions 자동 배포
