# SPIN LAB

드래그로 스윙하는 인터랙티브 탁구 게임.

**▶ 바로 플레이: https://hooni9807.github.io/spin-tt/**

로컬에서는 `index.html`을 브라우저로 열면 바로 실행됩니다. (설치 불필요, 단일 HTML 파일)

## 플레이 방법

- 공이 내 코트에 한 번 튄 뒤 **내 쪽 끝선 밖으로 나오면** 스윙합니다.
- 공 테두리 원: **WAIT**(흰색) → **READY**(금색) → **HIT!**(초록색) 순간에 스윙하면 PERFECT.
- 마우스 / 터치 모두 지원합니다.

| 조작 | 동작 |
|---|---|
| 공 오른쪽 아래 → 위로 드래그 | 루프 드라이브 |
| 공 왼쪽 아래 → 위로 드래그 | 백드라이브 |
| 아래로 끊어 드래그 | 커트 |
| 짧고 가볍게 드래그 | 쇼트 |
| 옆으로 쓸기 | 사이드스핀 |
| 빠르게 두 번 클릭 / 탭 | 스매시 |
| `E` 또는 필살기 버튼 (100% 충전 시) | 유성 드라이브 |
| 내 서브 차례: 탭으로 토스 → 떨어질 때 스윙 | 서브 (방향으로 회전 결정) |
| `Space` | 일시정지 |

## 서브

- 실제 탁구처럼 **2점마다 서브권이 바뀝니다** (10:10 듀스부터는 1점마다). 첫 서브는 AI.
- 내 차례가 되면 **공을 손에 들고** 있습니다. 화면을 누르면 **토스**, 공이 떨어질 때(초록 **HIT!**) 스윙하면 서브가 나갑니다.
  - 공은 탁구대보다 높은 곳에서만 칠 수 있습니다 (실제 규칙). 놓치면 다시 토스하면 됩니다.
- 스윙 방향에 따라 회전이 정해지고, **위아래 + 좌우를 섞을 수 있습니다.**

| 스윙 방향 | 회전 |
|---|---|
| 위 → 아래 | 하회전 (커트) |
| 아래 → 위 | 상회전 |
| 왼쪽 → 오른쪽 | 우회전 |
| 오른쪽 → 왼쪽 | 좌회전 |
| 대각선 (예: 왼쪽 위 → 오른쪽 아래) | 하회전 + 우회전 |

- 스윙이 빠를수록 빠른 서브가 됩니다. 궤적은 항상 내 코트에 한 번 튄 뒤 네트를 낮게 넘어 상대 코트에 들어가도록 자동 계산됩니다 (너무 빠르면 자동으로 속도를 줄임).

## 포핸드 / 백핸드

- 공 **오른쪽**에서 스윙 → 라켓이 몸 오른쪽, **검정 러버** (포핸드)
- 공 **왼쪽**에서 스윙 → 라켓이 몸 왼쪽, **빨강 러버** (백핸드)

## 라켓 선택

설정 카드의 **내 라켓**에서 고를 수 있습니다. 선택한 라켓·난이도·사운드·최고 랠리는 브라우저에 저장됩니다.

| 라켓 | 특징 | 타격 범위 | 파워 | 특기 |
|---|---|---|---|---|
| 쉐이크핸드 | 균형형 | 1.0 | 1.0 | **올라운드**: 타격마다 필살기 충전 +10% 추가 |
| 중국식 펜홀더 | 짧은 손잡이, 빠른 손목 | 0.95 | 1.08 | **빠른 쇼트**: 쇼트 속도 ×1.5 |
| 일본식 펜홀더 | 네모난 헤드, 코르크 손잡이 | 0.9 | 1.18 | **포핸드 강타**: 포핸드 드라이브 속도 ×1.25 |
| 수비수 라켓 | 크고 넓은 면 | 1.2 | 0.85 | **수비 특화**: 드라이브·스매시 등 모든 스윙이 강한 후진 회전의 커트(CHOP)로 나가 상대가 받기 어려움 |

## 캐릭터 모션

- 기술마다 실제 탁구 동작을 본뜬 스윙 모션이 나옵니다.
  - **루프 드라이브**: 낮게 무릎을 굽혀 공 아래에서 이마 위로 쓸어 올림
  - **백드라이브**: 배 앞에서 팔꿈치를 내밀며 바깥 위로 튕김
  - **쇼트**: 백스윙 없이 짧게 밀어 막음
  - **커트 / 수비 커트(CHOP)**: 어깨 높이에서 무릎 쪽으로 깎아 내림
  - **스매시**: 높은 타점에서 몸 앞을 가로질러 내려침
  - **사이드스핀**: 몸 앞을 옆으로 쓸기
- 공이 오면 무릎을 굽힌 준비 자세를 잡고, 좌우로 이동할 때는 사이드스텝으로 뛰어갑니다.

## 저장 / 이어하기

- 점수가 날 때마다 **점수 · 모드 · 필살기 게이지**가 브라우저에 자동 저장됩니다.
- 창을 닫았다 다시 열면 시작 화면에 **이어하기 (7 : 5 · 11점 경기)** 버튼이 나오고, 누르면 다음 서브부터 이어집니다.
- **플레이 시작**(새 게임)을 누르거나 11점 경기가 끝나면 저장이 지워집니다.
- 같은 기기 · 같은 브라우저에서만 이어할 수 있고, 시크릿 창이나 사이트 데이터 삭제 시 사라집니다.

## 모드

- **연습 랠리**: 리턴이 쉬워집니다.
- **11점 경기**: 11점 · 2점 차로 승리. 난이도(입문 / 보통 / 도전) 선택 가능.

캐릭터: 나 = 파란 사람, AI = 빨간 사람.
