# 임희범 키우기 · BeamRPG

> 마을의 탁구 고수들을 이기고, 선수촌의 탁구 마왕까지 도전하는 브라우저 성장 RPG.

**[게임 바로 하기](https://hooni9807.github.io/beamrpg/)**

## 게임 흐름

1. 리그 지도에서 열려 있는 마을을 고릅니다.
2. 일반 선수와 대결해 경험치를 얻거나, 불리하면 **도망친다**를 선택합니다.
3. 지역 보스를 이기면 다음 부수의 마을이 열립니다.
4. 레벨업 때 무작위로 나온 3개 강화 중 하나를 선택합니다.
5. 레벨 10에 도달하면 라켓 필살기를 사용할 수 있습니다.

## 리그 로드

| 지역 | 권장 레벨 | 보스 |
| --- | ---: | --- |
| 7부 마을 | 1 | 아재범 |
| 6부 마을 | 3 | 꿀잠범 |
| 5부 마을 | 5 | 리신범 |
| 4부 마을 | 7 | 퍼시벌 |
| 3부 마을 | 9 | 휴고범 |
| 선수촌 | 12 | 탁구 마왕 |

## 성장

레벨업 때 아래 능력치 가운데 3개가 무작위로 제시됩니다. 하나를 고르면 해당 능력치가 성장합니다.

| 능력치 | 효과 (1포인트당) |
| --- | --- |
| 파워 | 타구 속도 +5% |
| 회전 | 타구 회전 +5% |
| 컨트롤 | PERFECT 타이밍 폭 +3% |
| 풋워크 | 회전 공 실수 확률 −10% |
| 치명타 | 치명타 확률 +5% (타구 속도 2배) |
| 집중력 | 필살기 게이지 획득 +10% |

지역 보스는 그 마을보다 한 부수 위 실력으로 나오고, 선수촌의 탁구 마왕은 보스전 난이도입니다. 필살기 게이지는 리그 대결에서 레벨 10부터 찹니다(자유 플레이에는 제한 없음).

진행 기록은 같은 브라우저의 `localStorage`에 자동 저장됩니다.

## 레벨 마일스톤

| 레벨 | 해금 | 효과 |
| ---: | --- | --- |
| 10 | 라켓 필살기 | 선택한 라켓의 기본 필살기 사용 |
| 20 | 고요한 호흡 | 타이밍 판정 범위 +15% |
| 30 | 치키타 스파이럴 | 기본 필살기와 번갈아 발동하는 강한 횡회전 백드라이브 |
| 40 | 챔피언 심장 | 공 속도·회전 +10% |
| 50 | 제니스 오버드라이브 | 세 번째 필살기마다 발동하는 최종 초고속 회전구 |

## 조작

- 지도: 지역을 클릭해 이벤트를 시작합니다. **자유 플레이**로 일반 탁구 모드에 가고, 상단 **🗺 리그 지도**로 돌아옵니다.
- 대결: 공의 타이밍 링이 맞는 순간 드래그해 스윙합니다.
- 탭/클릭: 쇼트 또는 블록
- `Space`: 일시정지

## 로컬 실행

별도 설치가 필요 없습니다. `index.html`을 브라우저에서 열면 됩니다.

## 배포

`main`에 푸시하면 [GitHub Actions](.github/workflows/deploy-pages.yml)가 GitHub Pages로 자동 배포합니다. 저장소에서 처음 한 번만 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정하면 됩니다.

## 기술

- 단일 HTML/CSS/JavaScript 게임
- Canvas 기반 탁구 경기
- GitHub Pages + GitHub Actions 자동 배포
