# BeamRPG · 대환장 파티

> 희범의 집부터 챔피언의 경기장까지. 7부부터 1부까지 마을을 여행하고, 선수촌의 탁구 마왕에게 도전하는 브라우저 성장 RPG.

**[게임 바로 하기](https://hooni9807.github.io/beamrpg/)**

## 짧은 프롤로그

새 여정을 시작하면 **2023년 3월**, 일본식 펜홀더 고수를 꿈꾸는 임희범이 라켓을 쥐고 탁구 여정을 떠나는 네 장면이 나옵니다. 실제 게임 지도 위에 카메라 연출과 짧은 대사를 더했습니다. 다음 버튼으로 읽는 속도에 맞춰 넘기거나 건너뛸 수 있습니다.

7부 보스를 이기고 **6부 마을에 처음 들어가면 날짜가 2024년 10월 16일로 바뀌는 전환 장면**이 나옵니다. 쉐이크핸드로 전환할지, 일본식 펜홀더를 계속 쓸지 선택하며 선택한 라켓을 무료로 지급하고 장착합니다. 장면은 건너뛸 수 있지만 라켓 선택은 해야 합니다. 선택은 저장되어 재접속할 때 다시 묻지 않습니다. 프롤로그는 **안내 → 스토리 다시 보기**에서 다시 볼 수 있습니다.

## 게임 흐름

1. 시작 캐릭터는 **희범**, 기본 라켓은 **일본식 펜홀더**이며 첫 게임은 희범의 집에서 시작합니다. 포획한 동료는 나중에 일반 전투의 출전 캐릭터로 선택할 수 있습니다.
2. 집에서 쉬고, 마을 상점에서 장비를 구하거나 강화소에 들르고, 의뢰인 나래의 퀘스트를 받아 보세요. 카메라가 희범을 따라 넓은 지도를 비춥니다.
3. 마을 외곽을 걷거나 부쉬에 들어가면 몬스터와 지역 라이벌을 만나 **기술을 선택하는 턴제 전투**를 펼칩니다. 전투 중 스핀 디스크로 상대를 포획할 수도 있습니다. **체육관 보스**는 기존 탁구 스윙 경기로 대결하며, 이기면 다음 마을이 열립니다.
4. 레벨업 때 무작위로 나온 3개 강화 중 하나를 선택합니다.
5. 레벨 2 / 4 / 7 / 10 / 13에 일반 몬스터 전투에서 직접 고르는 새 기술을 배웁니다.

## 일반 몬스터 전투와 HP

포켓몬 본편의 기술 선택·PP·상성 구조를 참고한 턴제 전투입니다. **상대 HP를 먼저 0으로 만들면 승리**합니다. 마을마다 퐁글이·빙글젤리·가시커트와 그 지역의 라이벌 캐릭터가 야생 상대로 등장합니다. 주머니에서 고른 희범 또는 포획한 동료가 출전합니다.

- **기술:** 출전 캐릭터가 기술 하나를 사용한 뒤 상대가 기술 하나를 사용합니다. 상대 행동이 끝나면 다시 내 차례입니다. 먼저 쓰러진 쪽은 반격하지 않습니다. 기술마다 다른 시전·이동·타격 효과가 순서대로 재생됩니다.
- **데미지:** 레벨·위력·공격/방어 또는 특수공격/특수방어에 명중률·급소·데미지 변동을 적용합니다. 회전 커트는 상대 스피드를 낮출 수 있고, 철벽 준비는 방어·특수방어를 올립니다. 능력 변화는 해당 전투에만 적용합니다.
- **DP 타입 상성:** 포켓몬스터 DP의 노말·불꽃·물·전기·풀·얼음·격투·독·땅·비행·에스퍼·벌레·바위·고스트·드래곤·악·강철 17타입의 단일 타입 상성을 사용합니다. 희범은 새 여정 시작 시 무작위 타입을 받고 저장되며, 야생 상대는 조우마다 무작위 타입을 받습니다. 포획한 동료의 타입은 그대로 유지됩니다. 보스와 코치는 마을별 고정 타입이라 다시 싸워도 바뀌지 않습니다. 기술마다 타입이 있어 상대에게 2배, ½배, 무효 또는 일반 피해가 적용되고, 출전 캐릭터의 타입과 같은 기술은 1.5배 피해를 줍니다. 전투 화면의 기술 버튼은 **2배면 노란 테두리, 반감이면 빨간 테두리**로 표시합니다.
- **PP:** 기술마다 사용 횟수가 있습니다. 모두 소진하면 반동 피해를 받는 최후의 발악을 사용합니다. 라켓을 바꾸어도 이미 사용한 필살기 PP는 회복되지 않습니다.
- **아이템:** 시작 회복약 3개와 스핀 디스크 5개. 회복약은 HP 40을 회복하고 한 턴을 사용하며 치유 센터에서 25 G에 구입합니다. 스핀 디스크는 전투의 **아이템** 메뉴에서 사용하며 마을 상점에서 35 G에 구입합니다.
- **도망:** 성공하면 보상 없이 마을로 돌아갑니다. 실패하면 상대가 공격합니다. 스피드와 시도 횟수에 따라 성공률이 높아집니다.

희범은 **HP 64**로 시작하고 레벨마다 최대 HP가 8씩 증가합니다. 희범과 각 동료의 HP·PP는 별도로 유지됩니다. **희범의 집·각 지역 숙소·치유 센터에서 모두 무료로 완전히 회복**할 수 있습니다. 패배하면 현재 마을 치유 센터로 돌아와 치료받으며 경험치와 골드는 잃지 않습니다. 보스와 코치의 탁구 경기는 HP·PP를 소모하지 않습니다.

일반 전투는 한 턴이 끝날 때마다 자동 저장됩니다. 새로고침하거나 브라우저를 다시 열면 상대와 출전 캐릭터의 HP·PP·턴·스핀 디스크 수량을 이어받습니다. 승리·포획 결과는 결과 화면에서 마을로 돌아갈 때 한 번만 반영됩니다.

자신보다 레벨이 높은 일반 몬스터를 이기면 레벨 차이 1당 기본 경험치를 **50% 더** 받습니다(최대 +200%). 각 마을의 부쉬는 **진입할 때마다 95% 확률**로 조우를 판정합니다. 부쉬 바깥의 안전 구역과 일반 외곽 조우 규칙은 그대로 적용됩니다.

## 포획과 동료 성장

일반 전투의 **아이템 → 스핀 디스크 사용**으로 야생 몬스터나 지역 라이벌을 포획합니다. 시작할 때 5개를 받고 각 마을 상점에서 1개에 35 G로 보충합니다. 상대의 남은 HP가 낮을수록, 출전 캐릭터의 레벨이 상대보다 높을수록 포획 성공률이 오릅니다. 전투 화면에 현재 확률이 표시됩니다. 던질 때마다 1개를 쓰고 실패하면 상대가 한 번 행동합니다. 보스와 코치의 탁구 경기는 포획 대상이 아닙니다.

희범과 포획한 동료는 **각자의 레벨·경험치·HP·PP**를 가집니다. 일반 전투에서 승리하면 그 전투에 출전한 캐릭터만 경험치를 얻습니다. 지도 위 희범은 계속 주인공이고, 상단 **주머니**에서 다음 일반 전투에 출전할 캐릭터를 고릅니다. 주머니에는 동료의 타입·성급·스탯·경험치와 회복약·스핀 디스크·장비 보유 현황도 표시됩니다.

같은 **종류·성급 3마리**를 모으면 자동으로 하나로 합쳐져 다음 성급이 됩니다. 1성 3마리 → 2성 1마리, 2성 3마리 → 3성 1마리이며 **5성까지** 올릴 수 있습니다. 성급마다 최대 HP·공격·방어·특수공격·특수방어·속도가 18%씩, 급소 확률은 2.5%p씩 증가합니다. 합성에 사용된 캐릭터의 누적 경험치도 합쳐집니다. 동료는 최대 200마리까지 보관하며 주머니에서 확인 후 놓아주어 공간을 만들 수 있습니다.

## 마을과 생활 시설

건물은 입구에 닿으면 내부 지도로 이어집니다. 출구에 닿으면 마을로 돌아오고, 마을 귀환 지점에서는 바깥 리그 로드로 나갑니다. 지도나 목적지 목록을 선택하면 건물과 물을 피해 걸어갑니다.

| 시설 | 이용 내용 |
| --- | --- |
| 희범의 집 / 지역별 숙소 | 무료 HP·PP 완전 회복 + 공격형 휴식 버프 |
| 지역별 공원 | 별도 공원 지도를 산책 + 민첩형 휴식 버프 |
| 라켓 공방 / 장비 상점 | 라켓과 해당 마을 전용 장비·스핀 디스크 구입·착용 |
| 탁구채 강화소 | 라켓과 보유 장비를 골드로 최대 +5까지 강화 |
| 의뢰인 나래 | 마을별 일반 몬스터 토벌 의뢰 수락·보상 수령 |
| 랠리 카페 | 샌드위치 40 G: 다음 3번 승리 경험치 +20% |
| 트레이닝 센터 | 코치와 연습 경기, 마을별 첫 훈련 승리에 해당 마을의 일반 승리 XP 지급 |
| 치유 센터 | 무료 HP·PP 완전 회복 + 방어형 휴식 버프, 회복약 25 G 구입 |
| 리그 기념관 | 8개 지역의 보스 격파와 트로피 기록 확인 |
| 체육관 / 경기장 | 해당 마을 보스에게 도전 |

휴식하면 다음 **3번 전투**에 적용되는 버프를 얻습니다. 버프는 중첩되지 않으며, 다른 휴식 장소를 이용하면 새 버프로 교체됩니다. 일반 턴제 전투와 보스·훈련 탁구 경기 모두에 반영됩니다.

| 장소 | 버프 | 일반 턴제 전투 | 보스·훈련 탁구 경기 |
| --- | --- | --- | --- |
| 희범의 집 / 숙소 | 정비된 루틴 · 공격형 | 공격·특수공격 +15% | 타구 속도·회전 +15% |
| 공원 | 산책의 리듬 · 민첩형 | 스피드 +25%, 급소 +10%p | PERFECT 판정 폭 +20%, 게이지 획득 +20% |
| 치유 센터 | 회복 보호막 · 방어형 | 방어·특수방어 +25% | 회전 실수 확률 −20%, PERFECT 판정 폭 +10% |

집과 치유 센터는 HP·PP도 완전히 회복하며, 공원은 HP·PP 회복 없이 버프만 제공합니다. 카페 식사는 효과가 남아 있는 동안 다시 구매할 수 없습니다. 훈련 재경기는 연습용이며 추가 경험치·골드를 지급하지 않습니다.

새로 시작하면 **120 G**를 받습니다. 일반 승리 보상은 7부의 45 G부터 지역마다 10 G씩, 보스 승리는 120 G부터 지역마다 20 G씩 증가합니다.

| 라켓 | 가격 |
| --- | ---: |
| 일반 라켓 (특수 효과 없음) | 보조 라켓으로 보유 |
| 쉐이크핸드 | 120 G · 6부 전환 선택 시 무료 지급 |
| 중국식 펜홀더 | 150 G |
| 일본식 펜홀더 | 기본 지급 · 상점가 200 G |
| 수비수 라켓 | 180 G |

구입하거나 스토리에서 받은 라켓은 공방과 주머니에서 바꿀 수 있습니다. 기존 저장에서 장착한 라켓은 그대로 유지됩니다. **전통 펜홀더 스타일의 희범은 보스전에서 백으로 오는 공을 쇼트로만 받지만, 그 쇼트는 상대 코트로 1.35배 빠르게 갑니다.** 쉐이크핸드는 백핸드 드라이브를 사용할 수 있습니다. 6부 관장 꿀잠범은 쉐이크핸드에 롱핌플 러버를 사용해 백에서 블록·커트를 구사합니다.

주머니에서 **라켓·탁구복·탁구화·손목보호대·머리끈·미끄럼 방지 스프레이·손가락 보호대·테이핑**을 부위별로 하나씩 착용합니다. 마을마다 판매하는 장비 두 종류가 다르며, 장비에 따라 HP·공격·방어·특수공격·특수방어·스피드·급소 확률이 희범의 일반 전투에 더해집니다. 착용한 장비의 변화는 지도 속 희범에게도 표시됩니다. 강화소에서 강화하면 장비의 능력치가 더 오릅니다.

일반 몬스터 승리 시 **8% 확률**로 장비를 얻고, 보스를 이기면 **해당 마을 장비 하나를 반드시** 받습니다. 의뢰인 나래에게 받은 마을별 토벌 퀘스트를 마치면 별도의 경험치와 골드를 받습니다.

## 성장

희범이 레벨업할 때 아래 능력치 가운데 3개가 무작위로 제시됩니다. 하나를 고르면 해당 능력치가 성장합니다. 포획한 동료는 레벨과 성급에 따라 전투 스탯이 자동으로 증가합니다.

| 능력치 | 일반 턴제 전투 (1포인트당) | 보스·훈련 탁구 경기 |
| --- | --- | --- |
| 파워 | 공격 +5% | 타구 속도 +5% |
| 회전 | 특수공격 +5% | 타구 회전 +5% |
| 컨트롤 | 방어 +5% | PERFECT 타이밍 폭 +3% |
| 풋워크 | 스피드 +5% | 회전 공 실수 확률 −10% |
| 치명타 | 급소 확률 +5%p, 최대 50% | 치명타 확률 +5% (타구 속도 2배) |
| 집중력 | 특수방어 +5% | 필살기 게이지 획득 +10% |

지역 보스는 그 마을보다 한 부수 위 실력으로 나오고, 선수촌의 탁구 마왕은 보스전 난이도입니다. 탁구 경기의 필살기 게이지는 레벨 2부터 찹니다. 게이지가 찬 보스·훈련 경기에서는 현재까지 배운 기술 중 하나가 무작위로 발동합니다. 탁구 경기 중 **마을로 도망**을 누르면 보상이나 경험치 손실 없이 돌아옵니다.

레벨, 스탯, 보스 격파, 위치, 미선택 강화, 골드, 보유 라켓, 시설 효과, 희범과 동료의 성장·HP·PP, 회복약·스핀 디스크·진행 중인 일반 전투는 같은 브라우저의 `localStorage`에 자동 저장됩니다. 기존 `beamrpg.v3` 또는 이전 `beamrpg.v2`의 성장·보스 기록을 이어받으며, HP가 없던 이전 저장에는 현재 레벨의 최대 HP와 회복약 3개를 지급합니다. 새 게임은 희범의 집에서, 이어하기는 마지막으로 저장된 위치에서 시작합니다. 이전 버전에서 이미 열린 선수촌도 계속 방문할 수 있습니다. 로그인 없이 플레이할 수 있습니다.

장비의 보유 수량·착용 부위·강화 단계와 퀘스트 진행도도 같은 저장 데이터에 포함됩니다.

## 조작

- 지도: 클릭/터치, 목적지 목록, 방향키 또는 `WASD`, 화면 방향 버튼으로 이동합니다. 희범의 팔·다리가 움직이고 카메라와 미니맵이 현재 위치를 보여 줍니다.
- 입구·출구: 걸어서 닿으면 다음 지도로 이동합니다. 목적지 목록도 즉시 이동이 아닌 걷기 안내입니다.
- 시설: 내부 이용 지점에 닿거나 가까이에서 `E`를 누릅니다. 체육관에서는 보스 도전 버튼으로 대결을 시작합니다.
- 일반 상대: 마을 외곽을 걷는 동안 확률적으로 조우합니다. 부쉬에 들어갈 때는 95% 확률로 조우합니다. 원형 표식으로 돌아다니는 상대는 없으며, 가만히 서 있거나 광장·시설 주변·건물 내부·공원에 있으면 조우하지 않습니다. 입장·대결 종료 직후에도 잠시 안전하게 이동할 수 있습니다.
- 일반 전투: 기술·아이템·상태·도망 메뉴를 클릭/터치하거나 `Tab`·`Enter`로 선택합니다. 아이템 메뉴에서 회복약 또는 스핀 디스크를 쓸 수 있습니다. `Esc`는 기술 메뉴로 돌아가며 전투를 종료하지 않습니다.
- 보스·훈련 경기: 공의 타이밍 링이 맞는 순간 드래그해 스윙합니다. 탭/클릭은 쇼트 또는 블록, `Space`는 일시정지입니다.

## 저장과 Firebase

BeamRPG는 SPIN LAB과 **완전히 별개의 프로그램**입니다. 탁구 엔진 코드는 SPIN LAB에서 가져왔지만, 저장소·Firebase·온라인 방은 공유하지 않습니다.

- 기본은 기기 저장입니다. RPG 진행 `beamrpg.v3`, 경기 설정·기록 `beamrpg.game.*` (SPIN LAB의 `spinlab.*`와 섞이지 않음)
- **클라우드 저장(선택)**: 지도 화면의 **☁ Google 로그인**을 누르면 RPG 진행(레벨·경험치·스탯·위치·HP·코인·라켓 등)을 BeamRPG 전용 Firebase에 저장해, 다른 기기에서 같은 계정으로 로그인하면 이어서 할 수 있습니다.
  - 저장은 바뀐 뒤 8초 안에, 그리고 화면을 벗어날 때 올라갑니다. 로그인하면 계정에 저장된 더 최신 진행을 불러옵니다.
  - 진행이 있는 기기에서 처음 로그인했는데 계정에도 진행이 있으면 어느 쪽을 쓸지 묻습니다.
  - 로그인한 적 없는 기기는 Firebase를 아예 불러오지 않습니다.
- 탁구 엔진에 남아 있는 예전 SPIN LAB 온라인 기능(랭킹·PvP·설정 동기화)은 꺼져 있습니다(`index.html`의 `FIREBASE_CONFIG=null`).
- 온라인 방 ID 접두어: `beamrpg-` (SPIN LAB 방과 매칭되지 않음)

### BeamRPG 전용 Firebase 프로젝트

| 항목 | 값 |
| --- | --- |
| 프로젝트 | `beamrpg` (ID `beamrpg-e22ac`), 웹 앱 `beamrpg-web` · 애널리틱스·Gemini 끔 |
| 인증 | Google 로그인 · 승인된 도메인 `hooni9807.github.io`, `localhost` |
| Firestore | 서울(`asia-northeast3`) · 문서 `saves/{uid}` = `{data, rev, level, at}` |
| 보안 규칙 | [`firestore.rules`](firestore.rules) · 본인 `saves/{uid}`만 읽기·쓰기, 그 외 전부 차단 |
| 코드 | [`cloud.js`](cloud.js) (설정값 포함) |

규칙을 바꾸면 Firebase 콘솔 → Firestore → 규칙에 `firestore.rules` 내용을 붙여 넣고 게시합니다. 네이버 로그인을 쓰려면 BeamRPG용 네이버 앱과 [`naver-worker.js`](naver-worker.js) 워커를 따로 만들어야 합니다.

`main`에 푸시하면 [GitHub Actions](.github/workflows/deploy-pages.yml)가 GitHub Pages로 자동 배포합니다. 저장소에서 처음 한 번만 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정하면 됩니다.

## 기술

- 빌드 도구 없이 실행하는 HTML/CSS/JavaScript 게임
- `towns.js`: 마을 이동, 경로 탐색, 시설, 성장과 저장
- `towns-renderer.js`: Canvas 지도와 희범의 걷기 모션
- `towns.css`: 지도 HUD, 목적지 목록, 모바일 레이아웃
- `story.js` / `story.css`: 첫 실행 프롤로그와 다시 보기
- `combat.js`: 일반 전투 계산, 기술·몬스터, HP·PP와 전투 저장 검증
- `combat-ui.js` / `combat.css`: 턴제 전투 화면과 원작 캐릭터 애니메이션
- `collection.js`: 포획 동료의 개별 경험치·HP·PP·자동 합성과 저장 검증
- `equipment.js`: 마을별 상점 품목, 장비·강화 능력치와 전투 보상
- 기존 Canvas 탁구 대결 엔진 연동
- GitHub Pages + GitHub Actions 자동 배포

프롤로그는 [스타듀밸리의 새로운 생활을 시작하는 설정](https://www.stardewvalley.net/about/)과 [포켓몬의 마을을 거점으로 떠나는 모험](https://legends.arceus.pokemon.com/en-ca/story/)에서 도입 구성을 참고했습니다. 희범의 여정과 대사는 이 게임을 위해 새로 작성했습니다.

펜홀더·롱핌플 상대의 경기 특성은 [Butterfly의 펜홀더 공략](https://butterflyonline.com/playing-against-penholders/)과 [롱핌플 공략](https://butterflyonline.com/playing-against-pipsanti/)을 참고했습니다. 희범의 백 쇼트 제한은 **전통 펜홀더 캐릭터 설정**이며, 실제 모든 펜홀더 선수에게 적용되는 규칙은 아닙니다. 쇼트 속도 1.35배는 게임 밸런스 수치입니다.

일반 전투와 HP가 낮을수록 포획하기 쉬운 흐름은 [포켓몬 공식 전투 안내](https://diamondpearl.pokemon.com/en-us/trainersguide/fundamentals/battling/)를 참고했습니다. DP 시기의 17타입 단일 타입 상성과 기술 타입·같은 타입 보정을 적용했습니다. 스핀 디스크·포획 확률·3대 1 성급 합성은 BeamRPG만의 규칙이며, 캐릭터와 몬스터 그림은 직접 그렸습니다.

기술별 시전·충돌 연출은 [MDN Canvas 애니메이션 안내](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Basic_animations)를 참고해 직접 그렸습니다. 사용자가 애니메이션 줄이기를 설정한 경우 [MDN의 reduced-motion 안내](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40media/prefers-reduced-motion)에 따라 긴 연출을 생략합니다.
