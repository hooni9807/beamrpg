# SPIN LAB

드래그로 스윙하는 인터랙티브 탁구 게임. `index.html`을 브라우저로 열면 바로 실행됩니다. (설치 불필요, 단일 HTML 파일)

## 플레이 방법

- 공이 내 코트에 한 번 튄 뒤 **내 쪽 끝선 밖으로 나오면** 스윙합니다.
- 공 테두리 원: **WAIT**(흰색) → **READY**(금색) → **HIT!**(초록색) 순간에 스윙하면 PERFECT.
- 마우스 / 터치 모두 지원합니다.

| 조작 | 동작 |
|---|---|
| 공 오른쪽 아래 → 위로 드래그 | 루프 드라이브 |
| 공 왼쪽 아래 → 위로 드래그 | 백드라이브 |
| 아래로 끊어 드래그 | 커트 |
| 짧고 가볍게 드래그 | 쇼트 |
| 옆으로 쓸기 | 사이드스핀 |
| 빠르게 두 번 클릭 / 탭 | 스매시 |
| `E` 또는 필살기 버튼 (100% 충전 시) | 유성 드라이브 |
| `Space` | 일시정지 |

## 포핸드 / 백핸드

- 공 **오른쪽**에서 스윙 → 라켓이 몸 오른쪽, **검정 러버** (포핸드)
- 공 **왼쪽**에서 스윙 → 라켓이 몸 왼쪽, **빨강 러버** (백핸드)

## 라켓 선택

설정 카드의 **내 라켓**에서 고를 수 있습니다.

| 라켓 | 특징 | 타격 범위 | 파워 |
|---|---|---|---|
| 쉐이크핸드 | 균형형 | 1.0 | 1.0 |
| 중국식 펜홀더 | 짧은 손잡이, 빠른 손목 | 0.95 | 1.08 |
| 일본식 펜홀더 | 네모난 헤드, 코르크 손잡이, 강한 한 방 | 0.9 | 1.18 |
| 수비수 라켓 | 크고 넓은 면 | 1.2 | 0.85 |

## 모드

- **연습 랠리**: 리턴이 쉬워집니다.
- **11점 경기**: 11점 · 2점 차로 승리. 난이도(입문 / 보통 / 도전) 선택 가능.

캐릭터: 나 = 파란 사람, AI = 빨간 사람.
