# BeamRPG · 대환장 파티

> 마을의 탁구 고수들을 이기고, 선수촌의 탁구 마왕까지 도전하는 브라우저 성장 RPG.

**[게임 바로 하기](https://hooni9807.github.io/beamrpg/)**

## 게임 흐름

1. 시작 캐릭터는 **희범**입니다. 지도를 클릭하거나 방향키로 걸어 열린 마을 입구에 닿으면 들어갑니다.
2. 마을 안에서 걸은 거리에 따라 확률적으로 상대를 만나 탁구 대결이 시작됩니다. 가만히 서 있으면 조우하지 않습니다.
3. **보스 체육관**에 걸어가 해당 보스를 이기면 다음 마을이 열립니다. **마을 귀환** 표지로 걸어가 바깥 지도에 돌아오세요.
4. 레벨업 때 무작위로 나온 3개 강화 중 하나를 선택합니다.
5. 레벨 2 / 4 / 7 / 10 / 13에 새 필살기 또는 패시브를 배웁니다.

## 리그 로드

| 지역 | 권장 레벨 | 보스 |
| --- | ---: | --- |
| 7부 마을 | 1 | 아재범 |
| 6부 마을 | 3 | 꿀잠범 |
| 5부 마을 | 5 | 리신범 |
| 4부 마을 | 7 | 퍼시벌 |
| 3부 마을 | 9 | 휴고범 |
| 선수촌 | 12 | 탁구 마왕 |

모든 마을에 서로 다른 배경 색상, 건물, 일반 선수 3종과 보스가 있습니다. 권장 레벨은 안내이며 입장 조건은 직전 마을 보스 격파입니다. 이미 이긴 보스와도 다시 겨룰 수 있습니다. 일반 승리 경험치는 순서대로 70 / 90 / 110 / 140 / 170 / 220이며 보스는 해당 마을 일반 보상의 2배입니다.

## 성장

레벨업 때 아래 능력치 가운데 3개가 무작위로 제시됩니다. 하나를 고르면 해당 능력치가 성장합니다.

| 능력치 | 효과 (1포인트당) |
| --- | --- |
| 파워 | 타구 속도 +5% |
| 회전 | 타구 회전 +5% |
| 컨트롤 | PERFECT 타이밍 폭 +3% |
| 풋워크 | 회전 공 실수 확률 −10% |
| 치명타 | 치명타 확률 +5% (타구 속도 2배) |
| 집중력 | 필살기 게이지 획득 +10% |

지역 보스는 그 마을보다 한 부수 위 실력으로 나오고, 선수촌의 탁구 마왕은 보스전 난이도입니다. 필살기 게이지는 레벨 2부터 찹니다. 대결 중 **마을로 도망**을 누르면 보상이나 경험치 손실 없이 돌아옵니다.

레벨, 스탯, 보스 격파, 위치, 미선택 강화는 같은 브라우저의 `localStorage`에 자동 저장됩니다. 기존 `beamrpg.v3` 진행과 이전 `beamrpg.v2` 보스 격파 기록을 이어받습니다. 로그인 없이 플레이할 수 있습니다.

## 조작

- 지도: 클릭/터치한 위치까지 걷기, 방향키 또는 `WASD`, 화면 방향 버튼 누르고 있기. 희범의 팔·다리가 움직이며 걷습니다.
- 마을 입구·보스 체육관·귀환 표지: 걸어서 닿아야 이동 또는 대결이 시작됩니다.
- 일반 상대: 마을 내부에서 걷는 중에만 확률적으로 등장하며 지도 위를 원형 표식으로 돌아다니지 않습니다. 입장·대결 종료 직후에는 잠시 안전하게 이동할 수 있습니다.
- 대결: 공의 타이밍 링이 맞는 순간 드래그해 스윙합니다.
- 탭/클릭: 쇼트 또는 블록
- `Space`: 일시정지

## 로컬 실행

별도 설치가 필요 없습니다. `index.html`을 브라우저에서 열면 됩니다.

## 배포

`main`에 푸시하면 [GitHub Actions](.github/workflows/deploy-pages.yml)가 GitHub Pages로 자동 배포합니다. 저장소에서 처음 한 번만 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정하면 됩니다.

## 기술

- 빌드 도구 없이 실행하는 HTML/CSS/JavaScript 게임 (`towns.js` / `towns.css`: 마을 및 이동)
- Canvas 기반 탁구 경기
- GitHub Pages + GitHub Actions 자동 배포
