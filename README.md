# SPIN LAB

드래그로 스윙하는 인터랙티브 탁구 게임.

**▶ 바로 플레이: https://hooni9807.github.io/spin-tt/**

로컬에서는 `index.html`을 브라우저로 열면 바로 실행됩니다. (설치 불필요, 단일 HTML 파일)

## 온라인 1:1 (친구와 대전)

1. 한 명이 시작 화면에서 **온라인 방 만들기** → 4자리 **방 코드**가 나옵니다.
2. 코드를 카톡 등으로 보내고, 친구는 같은 주소에서 **방 코드 입력 → 참가**.
3. 연결되면 바로 11점 경기 시작. 각자 화면에서 **내가 항상 아래쪽**에 보입니다.

- 로그인 · 설치 없음. 서브 교대, 필살기, 라켓 선택 모두 그대로 적용됩니다 (상대 라켓 · 필살기도 보임).
- 방장이 공과 점수를 계산하고, 참가자는 자기 스윙을 판정해 보냅니다.
- 온라인 중에는 일시정지 · 이어하기 · 모드 변경이 꺼집니다. 다시 하기는 방장이 누릅니다.
- 연결은 PeerJS(WebRTC)로 두 기기를 직접 잇습니다. 같은 와이파이나 일반 인터넷에서는 대부분 잘 되지만, **일부 회사망 · 이동통신망에서는 연결이 안 될 수 있습니다** (중계 서버를 따로 두면 해결 가능).

## 플레이 방법

- 공이 내 코트에 한 번 튄 뒤 **내 쪽 끝선 밖으로 나오면** 스윙합니다.
- 공 테두리 원: **WAIT**(흰색) → **READY**(금색) → **HIT!**(초록색) 순간에 스윙하면 PERFECT.
- 마우스 / 터치 모두 지원합니다.

| 조작 | 동작 |
|---|---|
| 공 오른쪽 아래 → 위로 드래그 | 루프 드라이브 |
| 공 왼쪽 아래 → 위로 드래그 | 백드라이브 |
| 아래로 끊어 드래그 | 커트 |
| 짧고 가볍게 드래그 | 쇼트 |
| 한 번 탭 / 클릭 | **쇼트** |
| 같은 자리를 꾹 누르기 | **디펜스 쇼트** (각도를 숙여 막기) |
| 공이 오기 전 미리 두 번 탭 | **스매시** 준비 → 공이 오면 자동 스매시 |
| 필살기 게이지 100% 후 다음 타격 | 라켓별 필살기 (자동 발동) |
| 내 서브 차례: 탭으로 토스 → 떨어질 때 스윙 | 서브 (방향으로 회전 결정) |
| `Space` | 일시정지 |

## 기술 상성

상대 공의 종류는 공 테두리 원 아래에 표시됩니다 (**커트 ↺ · 드라이브 ↻ · 회전 ⟲ · 스매시 ⚡**). 맞는 기술로 받아야 넘어가고, 틀리면 네트에 걸리거나 테이블을 넘어갑니다.

| 들어온 공 | 넘어가는 기술 | 실패 |
|---|---|---|
| 커트 | 커트 · 드라이브 | 쇼트 · 스매시 → **네트에 걸림** |
| 드라이브 | 디펜스 쇼트(꾹) · 드라이브 | 커트 · 스매시 · 쇼트 → **테이블을 넘어감** (수비수의 커트는 OK) |
| 스매시 | **PERFECT 타이밍**의 쇼트 · 디펜스 쇼트만 | 그 외 → **테이블을 넘어감** (수비수는 예외) |
| 회전 (사이드스핀) | 스매시 · 쇼트 | 드라이브 · 커트 → **테이블을 넘어감** |

- 필살기는 상성과 관계없이 항상 넘어갑니다.
- 상대 AI도 드라이브 · 커트 · 회전 · 스매시를 섞어 보냅니다 (낮은 공은 스매시하지 않음).

## 서브

- 실제 탁구처럼 **2점마다 서브권이 바뀝니다** (10:10 듀스부터는 1점마다). 첫 서브는 AI.
- 내 차례가 되면 **공을 손에 들고** 있습니다. 화면을 누르면 **토스**, 공이 떨어질 때(초록 **HIT!**) 스윙하면 서브가 나갑니다.
  - 공은 탁구대보다 높은 곳에서만 칠 수 있습니다 (실제 규칙). 놓치면 다시 토스하면 됩니다.
- 스윙 방향에 따라 회전이 정해지고, **위아래 + 좌우를 섞을 수 있습니다.**

| 스윙 방향 | 회전 |
|---|---|
| 위 → 아래 | 하회전 (커트) |
| 아래 → 위 | 상회전 |
| 왼쪽 → 오른쪽 | 우회전 |
| 오른쪽 → 왼쪽 | 좌회전 |
| 대각선 (예: 왼쪽 위 → 오른쪽 아래) | 하회전 + 우회전 |

- 스윙이 빠를수록 빠른 서브가 됩니다. 궤적은 항상 내 코트에 한 번 튄 뒤 네트를 낮게 넘어 상대 코트에 들어가도록 자동 계산됩니다 (너무 빠르면 자동으로 속도를 줄임).

## 코스 (좌우 방향)

- **오른쪽 → 왼쪽으로 휘두르면 공이 왼쪽**, **왼쪽 → 오른쪽으로 휘두르면 오른쪽**으로 갑니다.
- 위아래로만 휘두르면 가운데 쪽으로 갑니다. 서브와 필살기도 같은 규칙을 따릅니다 (스매시는 직선).

## 포핸드 / 백핸드

- 공 **오른쪽**에서 스윙 → 라켓이 몸 오른쪽, **검정 러버** (포핸드)
- 공 **왼쪽**에서 스윙 → 라켓이 몸 왼쪽, **빨강 러버** (백핸드)

## 라켓 선택

설정 카드의 **내 라켓**에서 고를 수 있습니다. 선택한 라켓·난이도·사운드·최고 랠리는 브라우저에 저장됩니다.

| 라켓 | 특징 | 타격 범위 | 파워 | 특기 |
|---|---|---|---|---|
| 쉐이크핸드 | 균형형 | 1.0 | 1.0 | **올라운드**: 타격마다 필살기 충전 +10% 추가 |
| 중국식 펜홀더 | 짧은 손잡이, 빠른 손목 | 0.95 | 1.08 | **빠른 쇼트**: 쇼트 속도 ×1.5 |
| 일본식 펜홀더 | 네모난 헤드, 코르크 손잡이 | 0.9 | 1.18 | **포핸드 강타**: 포핸드 드라이브 속도 ×1.25 |
| ALC 카본 (비스카리아 스타일) | 거의 둥근 157×150mm 헤드, 플레어(FL) 손잡이, 5겹 나무 + 2겹 카본 | 1.05 | 1.1 | **카본 반발**: 드라이브 계열 속도 ×1.15, PERFECT 판정 범위 +25% |
| 수비수 라켓 | 크고 넓은 면 | 1.2 | 0.85 | **수비 특화**: 드라이브·스매시 등 모든 스윙이 강한 후진 회전의 커트(CHOP)로 나가 상대가 받기 어려움 |

### 라켓별 필살기

게이지가 100%가 되면 다음 타격에 자동으로 발동합니다.

| 라켓 | 필살기 | 효과 | 꼬리 색 |
|---|---|---|---|
| 쉐이크핸드 | **치키타** | 백핸드로 공 옆을 감아 올리는 강한 백드라이브. 전진 회전 + 옆회전으로 바나나처럼 휘어 반대쪽 코너에 꽂힘 | 주황 |
| 중국식 펜홀더 | **번개 속공** | 네트를 낮게 스치며 같은 쪽 코너로 꽂히는 초고속 직선 | 하늘 |
| 일본식 펜홀더 | **천둥 스매시** | 가장 빠른 일격, 상대 코트 끝 구석을 강타 | 노랑 |
| ALC 카본 | **카본 캐논** | 묵직한 고속 루프가 반대쪽 코트 끝 구석에 꽂힘 | 빨강 |
| 수비수 라켓 | **유령 커트** | 둥실 떠서 네트 앞에 툭 떨어지는 초강력 하회전 | 보라 |

## 저장 / 이어하기

- 점수가 날 때마다 **점수 · 모드 · 필살기 게이지**가 브라우저에 자동 저장됩니다.
- 창을 닫았다 다시 열면 시작 화면에 **이어하기 (7 : 5 · 11점 경기)** 버튼이 나오고, 누르면 다음 서브부터 이어집니다.
- **플레이 시작**(새 게임)을 누르거나 11점 경기가 끝나면 저장이 지워집니다.
- 같은 기기 · 같은 브라우저에서만 이어할 수 있고, 시크릿 창이나 사이트 데이터 삭제 시 사라집니다.

## 캐릭터 모션

기술마다 **백스윙 → 임팩트 → 마무리** 3단계 동작과 체중 이동이 나오고, 공을 치면 코치 노트에 그 기술의 자세 요령이 표시되어 따라 할 수 있습니다.

| 기술 | ① 백스윙 | ② 임팩트 | ③ 마무리 |
|---|---|---|---|
| 루프 드라이브 | 무릎 굽히고 라켓을 공보다 낮게, 체중은 오른발 | 골반을 돌리며 공 뒤를 위로 쓸기 | 라켓은 이마 앞까지, 체중은 왼발로 |
| 드라이브 | 허리 높이로 라켓을 뒤로 | 몸통을 돌리며 앞으로 밀어치기 | 눈높이에서 마무리 |
| 백드라이브 | 라켓을 배 앞으로, 팔꿈치는 앞으로 | 팔꿈치를 축으로 앞·위로 튕기기 | 눈높이 앞에서 멈추기 |
| 쇼트 | 몸 앞에서 짧게 | 공이 튀어 오를 때 밀기 | 바로 준비 자세로 |
| 커트 | 라켓을 가슴 쪽으로, 면을 열기 | 앞·아래로 공 밑을 깎기 | 팔을 거의 편 채 치는 방향으로 |
| 수비 커트 | 어깨 높이까지 들기 | 위에서 아래로 길게 깎기 | 무릎 높이까지, 자세는 낮게 |
| 스매시 | 어깨 뒤로 크게 | 높은 타점에서 몸 전체로 | 몸 앞을 가로질러 |
| 치키타 | 손목을 안쪽으로 감기 | 공 옆을 감아 올리며 손목 펴기 | 바깥 위로 높게 |

- 공이 오면 무릎을 굽힌 준비 자세를 잡습니다.

### 풋워크 (좌우 이동)

발이 한 걸음씩 땅을 딛고 움직이며, 남은 거리에 따라 스텝이 바뀝니다 (멀리 → 교차스텝 → 사이드스텝 → 원스텝).

| 스텝 | 언제 | 발 순서 (오른쪽으로 갈 때) |
|---|---|---|
| 원스텝 | 아주 가까울 때 | 오른발만 옆으로 내딛고, 왼발은 따라옴 |
| 사이드스텝 (샤세) | 중간 거리 | **왼발이 먼저** 오른발 쪽으로 붙고 → 오른발이 벌려 나감. 발은 교차하지 않음 |
| 교차스텝 | 멀리 | 왼발이 오른발 앞을 **가로질러** 넓게 → 오른발이 다시 나감 |

왼쪽으로 갈 때는 좌우를 반대로 합니다. 참고: [All About Table Tennis – Footwork](https://www.allabouttabletennis.com/table-tennis-footwork.html), [ActiveSG – Proper footwork](https://www.activesgcircle.gov.sg/learn/table-tennis/what-is-the-proper-footwork-for-table-tennis), [Modern Cross-step](https://protabletennis.net/content/modern-cross-step)
- 참고: [Critical Features of the Forehand Topspin](https://protabletennis.net/content/critical-features-forehand-topspin), [How to Play a Backhand Push](https://www.experttabletennis.com/how-to-play-a-backhand-push-in-table-tennis/), [Backhand Push (tabletennisteacher)](https://tabletennisteacher.com/learn-backhand-push/)

## 휴고범

우리가 플레이하는 캐릭터 중 하나. 점수판에 이름이 표시됩니다.

- **스플릿 스텝**: 상대가 공을 치는 순간 두 발로 살짝 뛰었다가 넓게 착지
- **준비 자세**: 다른 캐릭터보다 넓고 낮은 스탠스, 기다릴 때 발끝으로 리듬
- **휴고범 드라이브**: 더 깊이 앉아 라켓을 낮게 뺐다가 골반을 크게 돌려 머리 위까지 크게 마무리
- **PERFECT**: "촤!" 외치며 반대 손을 번쩍
- 모든 캐릭터 공통: 드래그가 빠를수록 팔로우스루가 크고, 좌우로 끌면 마무리도 그쪽으로 기움

## 리신범

우리가 플레이하는 두 번째 캐릭터. 시작 화면에서 휴고범 / 리신범 중 하나를 골라 시작합니다.

- 헤어밴드로 눈을 가리고 그 위에 안경, 웨이브 머리, 디지털 카모 티셔츠, 큰 스마트워치
- 반대 손 주먹을 들어 올린 무술 가드 자세, 짧게 끊어 치는 드라이브
- 스플릿 스텝 · 발끝 리듬, PERFECT 시 "용의 분노!"

## 랭킹

- 11점 경기(AI 상대)가 끝나면 닉네임을 넣고 **랭킹 등록** → 페이지 아래 **🏆 랭킹**에 표시
- **최고 랠리**: 그 경기에서 가장 길게 이어간 랠리 수 · **경기 승리 점수**: 난이도 × 10 + 점수 차 (예: 프로 11:3 → 58점)
- 지금은 **내 기기 랭킹**(상위 10). Firebase를 연결하면 모두가 보는 **전체 랭킹**(상위 20)으로 바뀝니다.

### 전체 랭킹 켜기 (Firebase)

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 프로젝트 만들기 (Google 애널리틱스는 꺼도 됨)
2. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**
3. Firestore **규칙** 탭에 저장소의 [`firestore.rules`](firestore.rules) 내용을 붙여넣고 **게시**
4. **프로젝트 설정(⚙️) → 내 앱 → 웹(</>) 앱 추가** → 나오는 `firebaseConfig` 값을 `index.html`의 `const FIREBASE_CONFIG=null;` 자리에 넣기
5. 저장소에 올리면 1~2분 뒤 사이트에서 전체 랭킹이 보입니다

`firebaseConfig`는 공개돼도 되는 값이고, 기록은 규칙상 **읽기와 추가만** 가능합니다 (수정 · 삭제 불가, 값 범위 제한). 점수는 브라우저에서 계산되므로 조작을 완전히 막을 수는 없습니다.

## 모드

- **연습 랠리**: 리턴이 쉬워집니다.
- **11점 경기**: 11점 · 2점 차로 승리.
- **난이도 5단계**: 1 입문 · 2 초급 · 3 보통 · 4 도전 · 5 프로. 단계가 오를수록 AI가 더 잘 받고, 서브 · 리턴이 빠르고, 스매시 · 회전공이 많아지고, 코스가 넓어집니다.

캐릭터: 나 = **휴고범** (초록 줄무늬 저지 · 안경, 기본 · 설정에서 파란 선수로 변경 가능), AI = 빨간 선수. 점수판 YOU 옆에 내 캐릭터 얼굴이 표시되고, 온라인에서는 상대에게도 내가 고른 캐릭터로 보입니다.
